 # ChestSnap

 Ever wanted to place your chests or crates on a grid? <br /> 
 Tired of putting them carefully? <br /> 
 This mod will solve this problem! <br />

 These buildings are supported:
* all vanila chests
* crates (BuildIt By OdinPlus)
* branch chest (Construction By MrSerji)
* apple, garlic, pepper, potato, salt, tomato Boxes (Valharvest By Frenvius)
* cultivated Ground (Valharvest)
